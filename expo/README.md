# Jobbo

Expo Router app for browsing and saving job listings.

## Requirements

- Node.js 20+
- npm

## Getting Started

```bash
npm install
npm run start
```

## Useful Scripts

```bash
npm run start
npm run start-web
npm run start-web-dev
npm run lint
```

## Project Structure

- `app/` route files and screens
- `components/` reusable UI
- `providers/` app state and data flows
- `mocks/` sample job data
- `constants/` shared theme values
- `types/` shared TypeScript types

## Notes

Native package identifiers live in `app.json` and can be updated before publishing.
